# 热点探索界面说明

## 这个界面是做什么的

热点探索界面是一个带缓存的内容情报台。

它不是普通搜索框，而是同时帮你做 3 件事：

1. 找合适的视频参考样本
2. 找科技 / 视频 / 营销 3 个行业的最新信息
3. 生成一段主题趋势摘要

## 这个界面能做什么

当前支持：

- 输入主题关键词
- 选择目标语言
- 选择国家
- 选择平台
- 选择分发方式
- 选择品类
- 读取已缓存内容
- 单独刷新行业情报
- 单独刷新热点视频

结果区会显示：

- 行业情报摘要
- 合适的视频
- 科技、视频、营销行业信息

## 左侧过滤器怎么用

### 主题关键词

这是最核心的输入。

例如：

- AI 眼镜
- 折叠屏手机
- 跨境美妆
- 预算不高的拍摄神器

它会影响：

- 主题趋势摘要
- 热点视频搜索词
- 行业文章搜索词

### 目标语言

这个字段不是“把页面翻译成某个语言”。

它的主要作用是参与趋势搜索上下文和缓存分组。

简单理解：

- 你勾选的语言越接近实际投放语言，趋势摘要越贴近对应语境

### 国家

决定系统按哪个市场抓取趋势和内容。

### 平台

决定你要研究哪种平台风格。

但这里有一个非常重要的限制：

热点视频模块当前重点支持的平台只有：

- `tiktok`
- `instagram`
- `x`

如果你选的是其他平台，行业摘要仍然能工作，但热点视频可能会退回到这几个支持平台做相近参考。

### 分发方式

可选：

- `Organic Post`
- `Branded Content`
- `Paid Ads`

它会影响搜索词方向。

### 品类

会影响系统搜索的内容方向。

例如：

- `electronics` 会偏数码测评与科技内容
- `beauty` 会偏美妆种草内容

## 按钮分别是什么意思

### 读取已缓存内容

这个按钮最容易误解。

它的真实意思是：

按你当前这一组筛选条件，优先读取上一次已经抓过的结果。

如果这组条件以前从来没抓过，系统会第一次帮你实时抓一遍，然后把结果缓存下来。

### 刷新行业情报

只刷新：

- 主题趋势摘要
- 科技 / 视频 / 营销行业信息

不会主动刷新热点视频。

### 刷新热点视频

只刷新“合适的视频”模块。

不会主动刷新行业情报。

## 右侧 3 个结果区怎么理解

### 行业情报摘要

这部分会显示：

- 最近更新时间
- 当前搜索 query
- 主题趋势摘要正文

如果主题关键词没填，这里不会生成真正的主题趋势摘要，只会提示你目前只展示行业信息和热点视频缓存。

### 合适的视频

这是参考样本区。

每个视频卡片通常包括：

- 封面图
- 平台
- 热度标签
- 标题
- 摘要
- 原视频链接
- 一键复制链接

这里适合做：

- 选题参考
- 开头钩子参考
- 视觉包装参考
- 内容节奏参考

### 科技、视频、营销行业信息

这里固定分成 3 个板块：

- 科技行业
- 视频行业
- 营销行业

每块里会有：

- 摘要
- 实际搜索 query
- 若干篇文章链接

## 状态标签是什么意思

### 尚未加载

当前模块还没有拿到结果。

### 展示上一次内容

你看到的是缓存，不是刚刚实时抓的。

### 已实时刷新

说明你刚刚点了刷新，系统已经重新联网抓过。

### 刷新失败，已回退到缓存

说明这次实时抓取失败了，但系统保住了上一次内容，不让页面变空。

## 它背后的后端逻辑

热点探索后端不是把一切都实时搜索。

它会把结果按筛选条件缓存到业务库 `trend_snapshots` 里。

后端流程大致是：

1. 把筛选条件整理成唯一 scope key
2. 先查询 PostgreSQL 里有没有对应缓存
3. 如果有缓存且你没点刷新，就直接返回缓存
4. 如果你点了刷新，就实时请求 Tavily
5. 请求成功后，把新结果写回 PostgreSQL
6. 如果实时请求失败但旧缓存还在，就返回缓存兜底

接口：

- `GET /trends`

后端实现：

- [trends.py](/Users/bailumac/Developer/my-grad-proj/backend/services/trends.py)

## 数据流动

热点探索的数据流是：

1. 前端把筛选条件发到 `/trends`
2. 后端先检查 PostgreSQL 缓存
3. 决定返回缓存还是实时抓 Tavily
4. 实时抓取成功后写入 `trend_snapshots`
5. 前端把结果分成 3 个区域展示

## 最推荐的使用方式

如果你是第一次用，建议这样操作：

1. 填主题关键词
2. 选国家
3. 选平台
4. 选分发方式
5. 选品类
6. 点“读取已缓存内容”

如果你觉得内容过旧：

- 想更新文章与趋势，点“刷新行业情报”
- 想更新视频样本，点“刷新热点视频”

## 这个界面的定位总结

热点探索不是直接产出脚本。

它的价值是给选题、内容方向和视频参考提供即时情报，是脚本生成前的调研入口。
