# 达人管理界面说明

## 这个界面是做什么的

达人管理是整个系统的人设与合作资料中心。

它主要负责两件事：

1. 维护达人资料
2. 给脚本生成和脚本审查提供达人风格信息

这意味着它不是一个单纯的联系人表，而是后续脚本链路的上游入口。

## 这个界面能做什么

当前达人管理界面支持：

- 新增达人
- 编辑达人
- 删除达人
- 查看达人总览
- 刷新达人列表

当前表单字段包括：

- 达人名称
- 平台
- 合作进度
- 邮箱
- 近期视频链接
- 备注描述

表格里会展示：

- 达人 ID
- 名称
- 平台
- 邮箱
- 近期视频链接
- 备注描述
- 合作进度
- 操作按钮

## 这个界面背后的真实作用

达人管理除了保存 `talent_profiles`，还会同步维护 `users`。

原因是脚本生成模块读取的是达人风格档案，而这个风格档案来自 `users.style_prompt`。

系统现在的同步规则是：

- 新增达人时：自动创建一个对应的 `users` 记录
- 编辑达人时：同步更新 `users.name` 和 `users.style_prompt`
- 删除达人时：同步删除对应 `users`
- 删除达人时：历史 `scripts` 会保留，但 `user_id` 会被置空

所以你可以把它理解成：

- `talent_profiles` 是达人管理界面的业务表
- `users` 是脚本系统读取达人风格时的兼容层

## 页面怎么用

### 左侧编辑区

左侧的“新增达人资料 / 编辑达人”区域是录入区。

使用顺序：

1. 填达人名称
2. 填平台
3. 填合作进度
4. 可选填邮箱和视频链接
5. 在“备注描述”里写达人风格、人设、语言习惯、受众定位
6. 点击“新增达人”或“保存修改”

最重要的字段其实是：

- 达人名称
- 备注描述

因为“备注描述”会被同步成脚本生成时的人设风格提示词。

### 右侧总览区

右侧会显示 3 个统计值：

- 达人总数
- 平台数
- 推进中

这里适合快速看当前达人资源池情况。

### 下方资料表

下方是真正的达人资料表。

每一行支持：

- 编辑
- 删除

“近期视频链接”如果有值，可以直接点“查看视频”。

## 数据流动

新增 / 编辑达人时的数据流是：

1. 前端表单提交到 `/talents`
2. 后端写入 `talent_profiles`
3. 同步写入或更新 `users`
4. 返回最新达人资料给前端表格

删除达人时的数据流是：

1. 前端调用 `DELETE /talents/{id}`
2. 后端删除 `talent_profiles`
3. 同步删除对应 `users`
4. 把历史 `scripts.user_id` 置空
5. 返回删除成功

## 这个界面和其他界面的关系

它与脚本生成、脚本检查的关系最强。

原因是：

- 脚本生成会从达人资料中读取达人名称、平台、备注描述
- 备注描述会成为脚本风格的重要输入
- 脚本检查也可以关联达人资料，读取风格背景

## 使用建议

如果你希望生成出来的脚本更像某个达人本人，重点写好“备注描述”。

建议在备注里写：

- 人设标签
- 语言风格
- 常见表达
- 受众人群
- 内容擅长方向

不要只写“科技博主”这种过于简单的描述。

## 这个界面的定位总结

达人管理不是单纯的 CRM。

它是整个脚本系统的人设输入层，也是脚本生成质量最重要的上游来源之一。
